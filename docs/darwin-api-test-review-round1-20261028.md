## 修改范围

仅修改 `plugins/api-testing/skills/api-test-review/SKILL.md`，围绕收到评审回执后的分流：

- 区分内部评审记录 `verdict: pass/revise/blocked` 与公共工具 `phase: approved/revise/blocked`；正式公共回执须为 `phase: approved`，才能在已有授权范围内对同一 `runRef` 运行。
- `revise` 按 `reviewPath` 核查依据，在已获修订授权和剩余预算内传 `cases`、新 `outputPath`，同一 `runRef` 修订后重评；`blocked` 先保留原始原因与证据并停止。未知回执、缺失回执与直接抛错均停止，不伪造批准或 blocked。
- 将封闭的 reason 清单改为非穷尽已知值，补入真实存在的 `missing-business-facts`、`MODEL_TIMEOUT`、`CANCELED`，未列举值也原样保留。直接错误单独报告，不改码。
- 对应更新显性执行门禁和末条禁令，保持用户已有授权，不对同一已授权动作重复确认。

这些行为以当前公共入口、workflow 与 review 实现为依据。未修改插件代码、发现包装或其他技能，未新增依赖；纯文档更新，插件版本仍为 0.5.0。原有断言、独立模型与宿主批准边界保留，预算段落未顺手扩修。
