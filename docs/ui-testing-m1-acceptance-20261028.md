- A05-5：同一固定角色和部署的原正式批次有浏览器证据；[依赖恢复](../tests/scratch/ui-pms-m1-20261028/dependency-pinned/1793171838017/result.json)恢复的是 0.1.27 冻结依赖，未在 0.1.29 或变更后的真实部署重跑。合成 wrapper 变化仅证明该工程场景可发现失效并重新定位；未来变更不能直接沿用旧结论。
- A05-7：范围是测试账号对专用草稿的只读名称查询与重置。真实正常路径、请求及结果与隔离故障诊断分别留证；异常探针是断言检错能力，不等于真实服务异常验收。历史[六功能合成批次](ui-testing-evidence/optimization-u05-approved-run.json)含边界和权限检查，不替代真实角色验证。业务观察基线仍待产品确认，不能推断业务规则普遍正确。
- A09-1：逐条对账已完成，A05-5 的变化后真实浏览器适用性、产品预期确认和 A09-5 的实际加载仍是条件性或未知事项；A09-6 性能属于 M2，A09-8 按实际提交与远端核对。对账结论不替代独立评审，也不将范围外功能算作通过或失败。
