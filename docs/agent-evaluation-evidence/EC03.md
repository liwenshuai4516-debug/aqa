# EC03 — 评分引擎与基础规则

依据统一方案 §5.3、§8 与 EC03，以及 AC11/12/15/16/17。前置 EC02 已提交 `6d7733b`，评分基础已提交 `4268c8d`。本轮补齐七条规则、默认 profile、来源接线和离线工程验证。工程范围验证完成，结果见下方；M1 产品闭环与实际 Electron 接入仍待 EC04，不把本包测试当桌面验收。

## 实现与边界

- `registry.mjs`：可信发布代码的 adapter/evaluator/profile，精确版本、原子登记、依赖和 schema 子集校验、配置冻结。新增规则只需实现/注册/测试；不执行上传代码。profile.required 指必须成功处理的评分器，不新增用户业务条件。
- `evaluate.mjs`：只读封存视图，冻结契约与配置；规则没有 host/store/runner/model 参数。作业持久化、幂等、取消代次、异步超时、迟到隔离、保存失败和重启 unknown；显式新请求才重评。同步可信 JS 不可被计时器抢占，超时返回后拒绝结果，不宣称 CPU 沙箱。当前评分耗时以单调时钟记入可选 `job.elapsedMs`，与被测任务分账。
- `aggregate.mjs`：目标/约束/交付门禁分离；必需已知失败优先，建议项不硬扣分，未证实 N/A 不删分母。planned/executed/determinate/unknown/notExecuted/errors/excluded 与覆盖率分列，零分母 null。旧 schemaVersion 1 报告仍可读，不覆写历史。
- `evaluators/basic.mjs`：F01 产物存在/格式/明确 schema/摘要；F02 同 attempt 原生执行和逐项结果；F04 必要依赖；F05 结构化 boolean 声明；F06 工具结果分布；F07 重复候选。`profiles/internal.mjs` 默认注册七条固定 v1 规则，业务 checks 默认为空，必须显式冻结要求。
- `evaluators/metrics.mjs`：F08 按阶段记录单调区间并集、累计工作量与父子等待。跨 epoch 不拼墙钟；仅工具区间不能证明完整任务上限通过，但已观测超限可以失败。usage 按 callId 去重，provider measured 优先同调用估算；真实/估算/币种/被测/核验/评分分账；缺失未知，估算须价格版本，SDK 自报金额未定币种/版本时不计价。
- 宿主 SDK 选区投影复用 `nativeTestCompletion` 从实际 call/result 派生执行引用，不信 caller 自带 nativeExecution；查询旧状态不成为执行。宿主事件补进程 clockEpoch 和 performance.now；原工具 duration/watchdog 语义不变。
- `evaluation-artifact.ts`：tools 权限、可信发送方、所属会话与工作区绑定；最多 20 个显式路径、单文件 1MiB。拒绝越界/符号链接/凭据路径/非普通文件，非阻塞打开并核对读前后文件身份；不递归发现。二进制只摘要，正文有界、脱敏；派生字节摘要不冒充原字节。元数据完整与正文 truncated 分开，读取时点不能反推历史。不是对恶意宿主权限的 OS 隔离。

插件 0.3.0→0.3.1、SDK 0.1.4→0.1.5；新增宿主接口已同步类型、mock 与 API catalog。没有新增业务 runner、复制测试审批规则或修改业务结果。

## 环境与验证记录

macOS arm64、Node v23.10.0，独立分支 `codex/agent-evaluation`，临时 dataDir/agentDir/workspace，端口 >=8900。真实 CLI 与模型调用为零。原生测试复用既有 Newman/MCP 和 Playwright runner，设计评审响应是明确工程 stub，不算真实模型评审或真实桌面接入。

本轮首次规则回归发现 collector 新选项漏接默认参数，造成 14 项回归失败；另 1 项结构化声明夹具 producer 错误。修复参数与来源标记后，原 73 项通过。新增文件竞态测试初次使用不可 spy 的 ESM namespace，改为测试模块 mock 后通过；新报告计数断言初次指向错误层级，改为既有 summary.counts。完整类型检查发现新测试推断过窄，补 fixture 参数类型，无业务断言放宽。

原生初次评分因 macOS `/var` 与 `/private/var` 别名未关联同一工作区，全部保守未知；审计发现后使用真实路径比较并强制断言 trace 必须被选择，复跑得到 3 pass/1 fail/1 unknown。第一次编译服务冒烟出现 WebSocket 超时，失败原件保留在 `/var/folders/zl/dv8m7cfs0mj0j3vf6psss9y80000gn/T/agent-evaluation-server-b1ue4l`。服务的 ready 明确早于 attach/plugin 激活，测试原先只等 ready，存在启动竞态；改为等待真实插件 active，保留阶段/消息类型超时诊断，不修改服务行为或延长超时掩盖问题。

最终本轮 11 个测试文件 179 项通过、失败 0、跳过 0；完整 typecheck 5 配置、根 lint 与显式插件/新增测试 lint、协议结构与双端 v33、git diff --check 通过。协议历史启发式因无 tag 跳过，不计通过。编译服务 3 项通过，原生 runner 7 项通过，6 批评分预期与实际一致。单测与编译服务摘要见 [EC03-checks.json](EC03-checks.json)，原生结果与引用摘要见 [EC03-native.json](EC03-native.json)。
