# EC02 — 受控来源与证据封存

依据统一方案 2.1 的 EC02、EC00 冻结门槛和 EC01。用户已明确暂不做真实 CLI 实测，先完成内部诊断与离线工程验证。本包不调用真实模型、不安装到个人应用、不修改业务 runner。

## 范围与生产边界

新增 `server/agent/evaluation-evidence.ts` 读取 SDK 固定 entry ID 选区；ClientSession → AgentService → EngineService（含多引擎分发）→ PluginHost 接线仅承载已授权客户端/会话。未知客户端/会话拒绝，不沿用旧快照的全局回退。真实工作区 realpath 的摘要作为 workspaceId；请求体 owner/cwd 不能决定身份或原生读取路径。

插件增加 `adapters/pi.mjs`、`collect.mjs`；store 仅扩展显式子任务 attempt 关系。manifest 0.1.0→0.2.0，SDK 0.1.3→0.1.4 同步类型/mock，宿主 API 目录同步登记两个只读方法。没有生产 index、工具、技能或页面，因此不能安装为完整能力；EC04 再统一验证设置管理、快捷发现、禁用/重载与实际 Electron。

当前请求已授权实施计划中新增宿主接线。本包保留桌面历史 D02–D06 批准及哈希原件，不改写历史批准记录，不引用过去模型额度。核心变更限受控只读 API、纯协议类型与 SDK 对齐；没有修改 Agent 循环、工具执行/守卫、runner、模型配置或启动策略。协议继续 v33，使用既有插件通道；启动补丁仍在普通 runtime 导入前。

## 持久化与故障行为

按 attempt + sourceId + sourceEventId + sourceRevision 去重，内容修订冲突保留双方。正文/证据落盘后最后发布 checkpoint；相同请求返回已有回执，不重读原生来源。封存只接受 durable checkpoint，旧快照不随来源变更重写。

watch 仅显式注册；采集失败不抛回普通业务，并回调降级原因。同步读取/落盘开销仍须 EC04 实测，不在本包宣称性能门槛通过。最多缓存 1,000 个实时事件；溢出明确回调并在 checkpoint 保存缺口，重开 watch 才恢复接纳实时事件；取消/关闭注销监听，迟到回调不发布 checkpoint。故障后可重读已选持久源，未保存实时事件仍是缺口。实时来源仅作为部分观测，不将没有 start 或墙钟变化补成精确完整轨迹。

真实子进程在证据原子发布后以状态 73 退出，父进程确认退出后在新隔离副本恢复，原 writer.lock 与证据保持；确认只有一条持久证据、无提前 checkpoint，重采集最终得到三条唯一证据及一个 checkpoint。该检查模拟进程中断，不代表物理断电/磁盘设备耐久认证。

## 本轮执行证据

环境：macOS arm64，本机 Node v23.10.0；独立工作区 `codex/agent-evaluation`。共享既有依赖链接，仅使用临时数据目录和合成数据。隔离 PluginManager 实际加载本轮复制的插件模块，测试专用入口不冒充生产入口。

- `tests/unit/agent-evaluation-evidence.test.ts`：SDK 选区/预算/投影/脱敏/分页/缺子任务、持久去重/来源修订、进程退出恢复、原生回查、watch/取消、乱序/重复/墙钟变化。
- `tests/unit/agent-evaluation-host.test.ts`：真实 PluginManager + SDK 原型接线，可信 sender、拒绝未知客户端/会话、嵌套 subagent、tools 权限、原生读取工作区绑定。
- `tests/agent-evaluation-server-test.mjs`：经 ensureBuild 串行构建后启动隔离完整服务，真实 WebSocket/plugin 通道验证两个客户端各取自己的 SDK session、伪造 owner 无效、未知会话拒绝、只读查询不新建会话；3 项通过，无 prompt/模型调用。仅停止自己启动的进程，不使用端口杀进程清理。
- `tests/data-space-native-test.mjs`：本轮执行 7 项回归通过，真实 Newman / Playwright 对本地合成目标运行；模型评审使用明确控制 stub，没有真实模型调用。
- `tests/agent-evaluation-native-test.mjs <本轮原生产物目录>`：再经新 collector 只读导入、封存 5 个 API run 与 1 个 UI run，保留 passed/failed/unknown、原时间和摘要；相同请求零额外读取；篡改 UI 引用拒绝，旧快照仍可读。脚本不导入 runner，不发业务请求。
- 轻量本轮原生索引见 [EC02-native.json](EC02-native.json)，保留原产物目录与摘要，不复制整套依赖/大日志。原目录为临时路径，归档前不可当长期可用下载地址。
