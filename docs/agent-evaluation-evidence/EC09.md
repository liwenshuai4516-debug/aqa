### 实现结果

- 数据空间登记窄接口，评估只能查询当前工作区已配置通道的项目/环境、原生资产批次、既有 intake 回执和当前用例归属；可选 run 复用原 `sync-status` 只读投影。评估不读取数据空间私有文件，不触发导入、业务结果同步或 runner。
- `projectRef={spaceId,projectId}` 不随项目改名变化。环境引用摘要绑定 ID、所属项目、名称、地址及数据空间 `updatedAt` 保存版本；不返回参数或认证值，动态脚本输出不算配置保存版本。原生批次绑定 engine、规范 assetRef 及 revision，防止相同版本标签串批。
- F03@1 按明确用例集合逐条核对真实回执和有效回查，输出数量/项目归属及观察时点。缺回执、缺回查、旧版本、非可信自报保持未知；不能由本次观察倒推出任务结束时已入库或业务语义完成。75 和优先级比例仅属于夹具，不硬编码到规则。
- 保留 `internal@1` 旧七规则身份，扩展 profile 内容寻址。专项界面经确认派生新的冻结契约并保存来源报告 ID；旧契约/报告/人工复核不被改写，其他未满足条件仍然未知。
- 索引由数据空间原子持久化，键绑定主体、工作区、`evaluationId + projectRef`，报告摘要冲突拒绝覆盖。评估侧只追加不可变 `pending/failed/synced` 账本；重复请求只对账，确认 missing 后的新显式请求才重试索引，不重跑 Agent、不重新入库。
- 写索引要求专用 `tools:evaluation-index-write` 和原会话执行守卫；计划/只读/委派等限制在执行侧保持。只读状态查询不写远端索引或本地账本。来源删除、停用或版本冲突可见失败，坏索引/未知版本保留原件。
- 设置页、技能、`/` 发现、工具登记、禁启与重载持久性均复用并在实际 Electron 验证；新增 zh/en 专项面板、失败解释和显式恢复操作。未覆盖个人安装，不创建发布包。
