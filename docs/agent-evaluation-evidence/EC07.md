# EC07：固定离线产物核验

本轮范围：沿用 EC06 的 macOS arm64、固定无网 VZ 假 CLI，补齐约定数据产物快照、独立可信核验和外部阶段指标。真实客户端与模型继续按用户决定暂缓；不把固定假 CLI 当真实 Agent，也不执行产物代码或业务测试。

## 设计与边界

- 产物：目标结束后由受信 runner 枚举整个 `/ae/work`，包括点文件、未跟踪和事先约定的 `.ignored`；导出路径、类型和字节，宿主建立大小、SHA256、变更/删除清单与整份清单摘要。初态 `old.txt/deleted.txt/.ignored/tests.txt` 只在 `artifacts-*` 场景装载，基线摘要一起冻结。路径限 ASCII 安全组件、128 字节；32 条、每文件 512 字节、累计 8192 字节；协议另有限额。所有链接、特殊文件、越界、重复、超限、未完成清单拒绝核验，保留缺口；不跟随链接、不在宿主物化 guest 路径。
- 独立核验：唯一随受信代码登记的 `offline-json@1` 检查 `result.json`；`artifacts-crash` 是显式固定核验器崩溃诊断。预期和核验定义只留宿主/核验进程，不上传到被测 VM；平台仓库也不挂载给 VM。Agent 自写报告或改公开 `tests.txt` 不改变判定。此阶段不支持任意不可信 guest：沿用 EC06 的可信固定目标限制，串口 nonce 不是认证。
- 独立环境：每次新的 macOS Seatbelt 进程，无网络/写入/子进程，个人、临时及外部卷目录不可读，运行时自身资源只读例外；工作目录 `/`，清空继承环境，仅留固定 PATH 与适用 Electron 运行标记。普通 Node 另启权限模型；Electron 不支持该参数，隔离由相同系统规则强制。每次实探读取、写入、子进程与网络拒绝，任一失败即核验错误。限制为 2 秒、32 MiB V8 堆、32 KiB 输入和 8 KiB 输出；V8 堆限额不宣称操作系统 RSS 硬上限。
- 持久性：先独占保存核验 intent，绑定产物摘要、fixture 摘要、核验代码摘要和原执行配置，再启动。保存原生退出码/信号、逐项结果、日志和环境声明；统一 evidence/snapshot 封存。重封存复用原结果；控制端中断仅保留 unknown，不静默重跑。禁用/卸载/工具取消会中止当前核验，并逐次复验原授权。
- F09：只消费原宿主生产、与完整冻结清单对应的独立结果；`fail` 是产物不合格，可信核验器崩溃/取消/超限或采集缺口为 `inconclusive`。保留旧 `internal@1` 七规则身份，新增评分在原内容寻址配置中冻结 F09；旧快照不会凭空获得核验证据。
- F08：原单调时钟记录 setup/agent/cleanup，核验单列；agent span 包含原协议输出和产物冻结等待，不解释成模型思考。报告自己的 scoring elapsed 为 evaluation。五阶段已观测合计可与分项相加核对；跨进程时钟、人工/控制间隔不拼成虚构端到端墙钟。费用仍按 callId 去重，实际与带版本估算分账，缺 usage 未知；本轮真实模型费用调用为零，合成费用对照不冒充账单。
