## 真实环境阻塞的自行调查

用户授权测试环境写入并要求自行处理接入条件，已只读获取公开 HTML/JS，识别 `/api`、token 请求头、客户端代码头与登录/验证码形式；未猜测账号、读取个人凭据或借用用户浏览器会话。OAS 的未声明 security 不能证明无需登录，HTTP 200 和 _/_ 不能证明业务成功或 JSON。没有发真实业务 API 请求。

进一步探测系统自带 `/usr/bin/sandbox-exec`，只使用本轮临时合成 canary 与 loopback 端口。[探测摘要](isolation-followup.json)保留所有尝试。数值 IP 网络规则被拒绝；localhost 规则虽能解析，但严格文件白名单下 Node 在启动时终止，正负测试均未执行。allow-default 与宽文件控制能启动 Node，不能据此声称文件隔离通过。未将不通过的 profile 接入产品，也没有放宽 runner 的 loopback 限制。探测源码和原始文件在 `tests/scratch/api-testing-isolation-probe/`。

当前 goal 未达到“全部完成”。完成真实业务还需要可使用的专用测试鉴权与有可信依据的业务成功条件，以及经过真实 MCP/执行器和攻击探针验证的隔离方案；不能把单独 Node 探针或源码字符串检查替代该证据。真实无人值守还需同版本/环境人工验收和独立授权。P4 仅在出现实际输入/需求后逐项启动。
