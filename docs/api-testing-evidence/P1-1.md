# P1-1：本地契约、候选与固定模板

2026-10-21；macOS / Node v23.10.0。依据[实施计划](../api-testing-implementation-plan.md) P1-1；前置 [P0-2](P0-2.md) 受控 fixture 接线已验收，真实目标隔离仍阻塞。

本任务交付插件内可组合的[导入/编译模块](../../plugins/api-testing/suite.mjs)及[测试入口](../../tests/api-testing-suite-test.mjs)。没有新增可绕过评审的执行工具；用户工作流入口的组合留给 P1-2/P1-3，实际模型生成/独立评审留给 P1-4。不是完整业务主流程验收。

## 行为及限制

- `importContract` 只读绑定项目内、≤2 MiB 的 OAS 3.0 JSON，使用固定 `@apidevtools/swagger-parser@13.1.0`（MIT）校验和解析。先拒绝非内部 `$ref`，再禁用 parser 的 file/http resolver；缺引用、循环引用、重复/不存在的 operationId 明确失败。
- `designCandidates` 根据所选操作与明确 JSON 响应生成候选纲要、断言依据和缺失输入；不猜测业务 ID、负向输入与状态码映射。候选标 `needs-input`，不能直接编译成可执行用例。
- `compileSuite` 接受声明式用例，只生成固定 Postman 模板，断言使用 `pm.expect`/Chai。支持明确状态、JSON 字段存在/类型/枚举/有依据的确切值；保留稳定 case ID 和契约/业务规则来源。不接收任意脚本；字面量通过 JSON 转义。
- 负向用例需明确且已确认的输入与状态规则；只声明了 404，不代表任何错误输入都应返回 404。正常请求数据使用固定 `ajv@8.17.1`（MIT）校验；formats 不校验并记录未覆盖。可选字段强制存在、nullable 强制单类型、未声明状态/字段与无依据精确值均拒绝。
- JSON 请求/响应、标量 path/query 参数为当前范围；认证、header/cookie 参数、非 JSON、复杂序列化和条件断言明确阻塞。未支持 schema 关键字列在 manifest，声明为业务关键时阻塞；不宣称完整 JSON Schema 断言或边界覆盖。
- 来源保存前去除 example/examples 注解（保留同名业务属性），拒绝明显凭据值和含凭据 URL；不是通用敏感数据识别器，真实数据仍需人工净化。原始来源只存 hash。只保留本轮 fixture 和净化文档，无个人凭据。
- `saveDraft` 将净化来源、解析来源、用例、规则、集合、pending review 和 hash manifest 发布到项目内新目录；禁止覆盖和 symlink 越界。无数据库、可变资产索引或自动签发批准；该包始终为 draft。

[最终摘要](P1-1-summary.json)：设计/执行 10 项，10 项通过、0 SKIP。覆盖内部引用及同名字段保留、候选缺输入、正常输入边界、草稿与全部文件 hash、拒绝覆盖/越界、负向依据、错误断言/缺参数、未覆盖关键字阻塞、格式/引用/操作阻塞、认证阻塞和模板代码注入转义。模板转义用 Node VM 验证，**不是 Newman 执行或沙箱验收**；Newman 主流程在后续任务验收。

尝试历史见 [P1-1-attempts.json](P1-1-attempts.json)：一次失败是增加严格字段白名单后，候选先被字段检查拒绝，未先报告 needs-input；调整检查顺序后完整重跑，没有放宽断言。原始包/日志在 `tests/scratch/api-testing-p1-1/evidence/`。

本轮 typecheck、3 文件/23 项相关单测、lint、主要协议检查、build、diff 检查通过；协议 tag 启发式因无 tag 跳过。P0-2 在新增隔离依赖集下真实回归 15/15。没有宿主权限/UI/生命周期改动，不再次全跑核心冒烟；P0-2 已记录的脚手架基线失败仍未修复。

## 用户文档的只读接入结果

[接入摘要](business-intake.json)来自 GET 文档 `/v3/api-docs`，未调用业务端点。净化副本保存在忽略的 `tests/scratch/api-testing-business-intake/source.json`，不提交完整内部业务契约。

契约为 OAS 3.0.1、58 条路径，`createReserveProj` 对应 POST `/v1/web/proj-reserve/reserve-proj-list`。**格式和内部引用导入通过，但该操作的响应只声明 `*/*`，没有明确 JSON 媒体类型，仅声明 200。** 因此不能据此生成 JSON/负向业务测试；候选列表为空，需明确业务规则/媒体类型。未声明 security 也不等于运行时无需鉴权。环境、测试数据、写入范围、凭据引用与真实隔离仍未验证。
