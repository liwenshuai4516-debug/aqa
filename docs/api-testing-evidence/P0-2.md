## 范围与已知边界

- 新增 [插件入口](../../plugins/api-testing/index.mjs)，只向模型注册 `api_test_execute(runRef)`。底层真实 MCP server 工具 `runApprovedSuite` 为私有，不放入常规 MCP registry/config。
- [短期身份](../../server/plugin-mcp.ts)来自实际 `ClientSession` 插件工具适配器，绑定 client/conversation/project/plugin/tool，WeakMap 拒绝伪造、复制、过期及跨插件上下文。执行期间每 50ms 复核原会话、模式与权限，取消专属调用。前台切换保留原会话身份；原 session 被替换会取消。
- [runner 服务](../../server/api-testing-runner.ts)的受信 `approveFixture` API 手工批准集合/评审 hash、身份、fixture origin、runner 与诊断钩子字节；不向模型/插件开放签发 API。批准仅内存有效，一次引用仅尝试一次，重启不重发未知请求。
- run 身份先落盘，再创建专属 MCP 进程，清空继承环境，使用 run 专属 HOME/TMPDIR。超时/取消显式关闭并观察进程退出后释放项目锁；无法确认退出时保留 unknown 及项目锁。只处理自己的进程，不终止其他项目 runner。
- 插件内固定 Postman MCP 2.14.0 / Newman 6.2.2 / MCP SDK 1.27.1，锁文件固定传递依赖。直接复用未修改上游 executor，绕开云获取/上传。没有自研 HTTP/断言引擎。
- 仅接受 HTTP 127.0.0.1 且端口 ≥8900 的自包含 fixture；路径 realpath 绑定项目。网络钩子是诊断手段，**不能证明 OS 沙箱**；固定手工集合与字段白名单也不是恶意脚本隔离/通用脱敏器。P0-1 的真实目标隔离缺口仍有效。
- pi 路径已验证；未提供可信第五参数的其他引擎显式不可用；Windows 明确拒绝，Linux 未实测。没有新 wire 消息、设置或 UI。

[集成测试](../../tests/api-testing-controlled-test.mjs)复制插件到临时 data-dir，项目使用 mkdtemp，fixture 端口 19080–19179，依赖复用忽略的隔离安装。实际使用 PluginManager、ClientSession 适配器、真实 MCP SDK server、上游执行模块和 Newman；不以 mock MCP 回包代替执行。会话为内存测试对象，没有启动真实模型会话或读取个人配置。

最终[执行摘要](P0-2-summary.json)含 15 项检查、fixture 请求和源文件指纹：

1. 原始 MCP 工具未向模型注册。
2. 未评审包、未知引用不能发请求。
3. 集合 hash 被篡改后拒绝。
4. 计划/委派模式执行前拒绝。
5. 插件/工具关闭后缓存定义也不可执行。
6. 伪造身份不能调用内部 MCP。
7. 跨会话批准不可复用。
8. 正常真实 MCP 执行通过；前台切换不改变归属。
9. 重复引用不重发请求。
10. 项目互斥；取消只停止自己的 runner，另项目仍存活；中断保留 unknown。
11. 运行中切换模式会取消。
12. 原会话 session 被替换会取消，不向另会话写入。
13. 插件停用停止其 runner 并移除工具。
14. 总时限后进程退出，保留 unknown。
15. 使用新引用可继续，不自动重试旧引用。
