## 五组成对对照

优化前固定 `0.1.3` 的 Git 分发包；现行版 `0.1.18`。相同历史引用、相同 1/8 批数据集、相同四条查询路径，每进程一次首测及五次重复，交替前后顺序，共 10 个串行 worker、480 次查询。首次查询已被准备过程预热，重复样本先在每进程取中位数，再组成 5 对。最终轮没有并行启动本任务的浏览器或检查；机器后台负载未控制，逐 worker 记录负载。
