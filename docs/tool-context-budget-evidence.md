## 复现与修复

1. 门控只删除内置目录名称，未删除延迟名单中的插件/扩展工具：改为全注册表应用名单。
2. 恢复时把 SDK 默认活跃全集当作历史已加载集合：改从工具结果及成功加载回执恢复。
3. 插件在门控之后注册、刷新时只同步工具：注册提前，刷新后统一重放门控。
4. 没有 snippet 的扩展缺失目录摘要：复用现有 description 精简回退。
5. 延迟目录重复参数签名：去掉重复签名，工具加载后的完整参数契约保留。

## 生效与剩余风险

部署本轮构建后重启应用，再新建或重新打开会话。保持设置中的「工具按需加载」开启。
同一设置下工具加载前后 system 逐字节一致，旧工具声明保持前缀；插件开关和设置变化
会合理改变可见目录。长任务逐步加载的工具仍会累积，历史压缩丢失的加载回执可能需要
重新按需加载。DSH 无 pi 注册面，不适用该机制。未删除会话或清空个人配置。
