本批 UI 用例已明确获准录入所选测试环境所属项目，无需再次确认。UI 原生 cases ref 可以用于草稿入库，尚未批准设计或执行不阻止入库。

目前入库受阻：本轮没有可调用的原生 `data_space_*` 工具，也未提供实际 cases ref、所选 `envId`、所属 `systemId` 或当前工具 schema。无法核对完整范围和目标归属，不能编造引用、ID 或声称已导入。

能力与真实引用恢复后，下一步是：

1. 核对当前 schema，用 `inspect` 读取 cases ref 的完整用例范围，确认整份资产均属于本批授权。`import` 处理整份资产；若范围不符或无法确认，停止并列出差异。
2. 按所选 `envId` 确认所属项目及真实目录 ID，调用 `data_space_automation` 的 `import`，使用 `engine=ui` 和工具实际返回的 `assetRef`。未指定目录时按默认“测试用例 → UI用例”规则定位，已有目录复用；归属不明时停止。多功能映射只使用真实 ID，未明确映射的用例保留“待归类”。
3. 核对导入回执中的 `imported`、`duplicate`、`errors`、`unmatched`，再以相同引用和环境查询 `archive-status`，保留完整计数、待入库项及归类状态；`ok=true` 或导入数为 0 均不能单独证明全部已入库。

本轮未执行任何业务操作。整批用例的入库状态尚未核验，数量未知；没有可据以认定成功的回执。未绑定自动化资产、未执行测试、未生成或同步执行结果。后续绑定和执行仍须遵循各自门禁。
