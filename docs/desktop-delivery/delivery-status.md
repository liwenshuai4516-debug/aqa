# macOS 内部测试交付状态

当前目标尚未全部完成。本次交付仅支持已验证的 macOS arm64 内部测试；用户已要求暂不实施 Windows/Linux。版本 0.109.0，临时名称 Pi Agent Desktop，临时 App ID local.pi-agent.desktop。

安装文件位于项目根目录 release/：

- Pi-Agent-Desktop-0.109.0-arm64.dmg
- Pi-Agent-Desktop-0.109.0-arm64.zip
- SHA256SUMS.txt

DMG 可挂载后复制应用；ZIP 可直接解压。应用未签名、公证，正式分发尚未具备条件。测试使用 ZIP 解压到源码目录外的中文和空格目录，明确去除 PATH 中的 Node；这不等同于全新 macOS 用户或 Gatekeeper 下载隔离验收。

默认数据与个人 Web/CLI 隔离。首次启动选择工作区，再通过原设置页面配置模型。测试凭据未预装进交付物；日志和独立数据位置、启动与恢复说明见 desktop/README.md。

T13 修复了损坏更新配置导致启动失败的问题，并重新生成内部包与 SHA-256；更新渠道缺失或不合规时应提示不可用，应用继续运行。详见 T13-updater-startup.md。此前安装包证据属于对应阶段的旧产物，不能等同于新版完整重验。

新版生命周期重验当前受 macOS 锁屏影响：启动、鉴权与 SDK 检查通过，全屏/聚焦无法完成，失败证据已保留并请求解锁；Dock、恢复及端口完整流程须在解锁后继续重验。

已验证：独立工作区、包内 SDK、原生 PTY、资源服务、端口冲突与偏好恢复、Dock 重建、服务故障恢复、历史保留且不自动续跑、真实 Chrome 扩展和会话接管、D03 的真实 SSH/SFTP 读写上传及权限错误。真实 DeepSeek 已完成包内 SDK 和完整聊天发送链路，共 2 次请求，累计输入 3,235 / 输出 16 tokens。
