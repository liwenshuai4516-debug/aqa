## 实际修复及验证

真实录制曾超时：PMS localStorage 含普通字符串 `2.0`，保守脱敏误改 JSON-RPC 版本，SDK 无法识别已返回的消息。仅保留协议 framing，其余全部 payload（含扩展字段）继续用原生过滤。先复现失败，再修复；真实 SDK/MCP/Chromium 合成回归验证动作、固定采集、writer 一致和秘密不泄漏。

实际入库曾因“站点环境基址 / 同站点合同页面”不完全相等而被拒绝。data-space 0.17.2 仅在 UI 原生资产且明确选择环境时接受同 origin、路径边界内的页面；绑定、执行路由及同步使用同一判断。跨协议、端口、域名、兄弟路径拒绝，API 仍保持精确地址匹配；回归覆盖入库→绑定→route→sync 及拒绝路径。没有改变原环境配置或冻结测试资产。首次目录保存后的检查、回执 total 层级及重开导航定位失误均保留为跑器失败，不计产品失败。

完整 typecheck、lint、协议结构检查通过。协议历史启发式因无 tag 跳过；本轮相关单测通过。扩大执行的插件版本守卫因原有 db-client 锁文件改动未提升版本而失败，保留失败，不修改或暂藏该无关差异。详细数量与日志见证据索引。开始和结束 clean 均仅预览，0 项可清理。测试基于当前含其他既有未提交改动的工作区，不宣称干净检出复现全部准备链。

## 阻塞与剩余范围

原生 0.1.18 将认证执行的图片与部分 trace 资源保留在工作区外的私有目录，公开副本缺少这些附件。当前结果核验据此强制 partial，独立模型不能覆盖这项硬条件。原始私密材料没有复制进工作区归档、项目文档或 Git；没有删改隐私附件声明、修改既有 run、放宽断言或将台账“未知”改成“通过”。后续须在原生维护源实现有权限边界和归属核验的私密证据审查，再重新解析和审查报告；不得直接修改安装目录或手写批准。

设计/结果评审合计 3 次的授权已用满，保守费用预留合计 0.331081 美元以内，非供应商账单；原匿名候选剩余 2 次仅设计额度未使用。用户另已明确批准冻结源码、脱敏回执和页面可见业务记录发往 api.sudorelay.com 的 gpt/gpt-6.1-sol，不包含原始认证文件。若需要后续付费结果评审，仍须单独补调用次数授权；当前不请求一项会被现有硬门禁阻断的付费调用。

查询断言检查请求名称/第一页和 HTTP 2xx，重置检查输入清空、无名称/第一页及 HTTP 2xx。HTTP 2xx 不证明后端业务码、列表行过滤或业务数据正确。产品 token-only 录制未证明所选租户；合同发起/审批、其他角色及跨租户、原三条源码草稿的真实测试、外层真实模型自主规划均未验证。外层工具分派使用本机控制 provider，独立评审使用真实模型，两者分别计量。

当时执行资产及绑定引用本机私有临时工作区，原件曾保留以续跑；2026-10-28 复核时该目录已不可访问，见下文。迁往长期工作区需走原生迁移、重新核对环境与批准，不能复制私有 authority 冒充已批准迁移。公开证据压缩归档有逐文件摘要，足以复核本轮统计和接线记录，但不代替私有原始附件。
