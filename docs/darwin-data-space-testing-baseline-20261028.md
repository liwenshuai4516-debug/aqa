## 建议的第一轮及确认点

最大加权结构短板为维度 2：`12×(10−7)/10=3.6`。建议只改善工作流导航：将“先定位，后交接”第 2 步已有规则整理为“读取 → 条件刷新 → 同目标复核 → 失败停止 → 原生预检”的短步骤／分支表，保持原参数、授权与停止条件；不新增依赖或业务规则。修订／截断遗漏随后复测观察，不能假定排版调整已解决它。

确认进入 Phase 2 后才实施，冻结改前／改后、复跑三个问题，并由三个新评委同次比较两版。保留／回滚只依据原始 paired 判断与语义回归，不依据绝对分涨跌；字节上限为本基线的 150%。完成本技能后再次等待用户确认，不进入第二项。
